## 3. Value added to the user — what no cited competitor offers

1. **One pipeline, one wallet** — discovery → validation → financials → documents → marketing in a single system; every incumbent covers one slice.
2. **Pay-per-outcome, not per-seat** — £1 = 100 ACU with every price shown before commit; incumbents bill $20–$250/mo whether you ship or not.
3. **Country-grounded, frontier-market first** — Kinshasa, Lagos, Nairobi get the same depth as London; CB Insights and Exploding Topics are US/EU-centric; nobody else prices for dollarized economies.
4. **Deterministic, interrogable scoring** — PRS/CS/PSS with hard GO/NO-GO bands; Validator-style tools return prose, not reproducible arithmetic — and we say NO GO when we mean it.
5. **The £10k capital class** — every result is realistically fundable; no incumbent constrains output to the user's actual budget.
6. **Capital-bracket fairness** — bigger ventures pay more, small founders pay least; unique in the market.
7. **Investor-grade artefacts from one evidence base** — the deck's numbers ARE the forecast's numbers; a Slidebean deck and a LivePlan plan never reconcile.
8. **100 free welcome ACUs, no card** — vs. 7-day trials with card capture across the category.
9. **Trust architecture as product** — E2EE, human-only access, honest probabilistic labelling; none of the cited tools markets verifiable security posture.
10. **Institutional surfaces included** — incubator cohort pools and Government Mode observatory; the only comparable (CB Insights enterprise) starts ~$25k/yr.
