# Truth Audit — does the product do what it claims?

Each headline claim traced to the real code path. Classification:
REAL (works end-to-end) · PARTIAL (works with caveat) · STUBBED (mock/placeholder) ·
ABSENT (UI/copy only) · BROKEN.

| # | Public claim | Status | Evidence / code path |
|---|---|---|---|
| 1 | "Score any business idea free, instant, no signup" | **REAL** | `index.html` `#freeScore` → a pure, deterministic hash-seeded function (FNV hash of idea+country → pillar values, weighted 0.35/0.30/0.35). Rendered live in the browser walkthrough: typed idea → "6.3 CONDITIONAL GO". No signup, no gateway. |
| 2 | Search Canvas returns ranked, scored niche opportunities for a country | **REAL** (model-driven) | `/v1/generate` with `NICHE_SCHEMA`; walkthrough rendered **3 ranked cards** with confidence + PRS/CS/PSS + financials. Real model needs a live key; proven end-to-end on the MOCK provider. |
| 3 | "Deterministic scoring — a pure function does the arithmetic; identical inputs → identical scores" | **PARTIAL** | TRUE for the **free** homepage score (literal pure function). The **paid search** pillar + `confidence` scores are produced by the **AI model** against a fixed rubric schema (`search.html:765` NICHE_SCHEMA), not a separate pure function. Grounded in real data (claim 4) but not bit-reproducible. **Recommend softening the "pure function does the arithmetic" wording for the paid path.** (Defect D-02) |
| 4 | "Grounded in your country's real market data" | **REAL** | `marketdata.js` fetches World Bank indicators (keyless, `api.worldbank.org/v2`), cached, injected into the generation system prompt. Fails soft. |
| 5 | "CFO-grade 3-year financials + downloadable Excel model" | **REAL** | `/v1/document` (forecast/pnl) + `nf-xlsx.js` = a real dependency-free OOXML workbook writer. |
| 6 | "End-to-end encryption, AES-256 at rest" | **REAL** | `wallet.js:35/43` `aes-256-gcm` createCipheriv/Decipheriv; passwords `scryptSync` (`auth.js:41`); TLS via Caddy. (Not "unhackable" — never claimed.) |
| 7 | "Never charged for a failed/incomplete search" | **REAL** | `server.js` structured-output guard: validates usable output before settling; retries once; releases hold + 503 on failure. Covered by `test/generate-output-guard.js`. |
| 8 | "Human-only — bots blocked at signup/login" | **REAL** | Proof-of-work challenge (`human.js`); signup in the browser walkthrough solved the PoW in-page before the account was created. API signup without a valid proof is refused. |
| 9 | Payments (Stripe + KODA mobile money) | **REAL** (sandbox-verified) | Live adversarial run: valid signed Stripe webhook credited; replay was idempotent; bad signature rejected (400). KODA path present; timestamp-replay window is weaker than Stripe (Defect D-03). Real settlement needs live provider contracts/keys. |
| 10 | Growth Partner referral programme | **REAL** | `/v1/referrals/*`, commission + reversal + lifetime cap; covered by `test/referrals.js` + `moneyleaks.js` F3e/F5. |
| 11 | Government Mode / Incubator cohort | **PARTIAL** | `government.html` is a complete page but **not yet linked in the product nav** (reachable by URL / article links). Honest "mode" page; not wired into the main journey. Not on a money path. |
| 12 | Landing "$1.24M" worked-example dashboard figures | **REAL (labeled)** | Hard-coded but **explicitly labeled "Illustrative worked example"** and overwritten by `GET /v1/showcase` when the operator publishes a real one. Not fake data posing as real. |

**No STUBBED-as-real or BROKEN claims found on money or critical paths.** The mock
provider's placeholder text is itself labeled "generated by the gateway mock provider
… without API keys" in the UI, so even the demo content is not misrepresented.

**Novice value test (Mind 2, mobile, slow-3G):** from a cold start, a first-time user
reached a scored result (free score) in seconds and a full ranked search after a
sub-minute signup — core value is reachable unaided on a phone. Friction notes in
`defects.md` (D-04 cookie banner overlap, D-05 wallet-sync race).
